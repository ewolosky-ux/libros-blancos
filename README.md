# Los Libros Blancos

Exposición digital interactiva en español sobre la evolución de la política británica en Palestina entre 1922 y 1939.

## Desarrollo local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

El proyecto usa Vite y React. Vercel detecta automáticamente la configuración: comando de compilación `npm run build` y directorio de salida `dist`.
